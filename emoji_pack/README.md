# Пак тгп-эмодзи бота

`manifest.json` — название пака и список иконок: `имя_файла: [эмодзи, которые она заменяет]`.
Первое эмодзи в списке — основное, остальные — псевдонимы.
Рядом лежат PNG 100×100 с прозрачным фоном, по одному на иконку (`имя.png`).

Бот (владелец, в личке): `/emojipack sync` — создать пак или обновить его по этой папке.
