# Паки тгп-эмодзи бота

`packs.json` — список паков (порядок важен: следующий перекрывает предыдущий, если эмодзи совпадают).
В каждой папке: `manifest.json` (title, name_prefix, repaint, icons: имя → [эмодзи]) и PNG 100×100 по одному на иконку.

* `main` — белые иконки, пак с перекраской под цвет текста (видны на любой теме).
* `color` — цветные иконки (✅ ❌ 🟢 🔴 ⭐ 🏆 …), цвет фиксированный.
* `svg/` — векторные исходники.

Бот сверяет паки при каждом запуске; вручную: `/emojipack sync` (владелец, личка).
