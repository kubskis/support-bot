
`a_main`, `a_color` — анимированные версии только для тех иконок, где движение уместно (WEBM VP9 100×100, 2 с, с альфой). Остальные остаются статичными. Перекрывают статичные при `/emojipack anim on` (по умолчанию включено).

**Новые эмодзи.** Если в боте появился эмодзи без иконки: добавьте его в `ICONS`/`ALT` в `emoji_pack/tools/gen_new_icons.py`, запустите скрипт и закоммитьте. При следующем запуске бот сам добавит иконку в пак, а автозамена подхватит её (в `EMOJI_IDS` вручную ничего писать не нужно). Иконки на inline-кнопках ставятся автоматически по эмодзи в начале текста.
